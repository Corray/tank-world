## 1. 项目定位

桌面浏览器端的经典坦克大战（Battle City 风格）单机游戏。玩家用键盘操控坦克，在格子地图中消灭全部敌方坦克并保卫基地。

## 2. MVP 功能范围

### 2.1 范围内（In Scope）

| # | 能力 | 说明 |
|---|------|------|
| F1 | 单张地图 | 格子制战场，含砖墙（可破坏）/ 钢墙（不可破坏）/ 空地 / 基地 |
| F2 | 玩家坦克 | 键盘四向移动 + 射击，固定出生点，有限命数 |
| F3 | 敌方坦克 | 自动出生、自动移动与射击，共 3 种类型 |
| F4 | 子弹与碰撞 | 子弹摧毁砖墙 / 被钢墙挡 / 命中坦克与基地的判定 |
| F5 | 胜负判定 | 敌人全灭 = 胜；基地被毁或玩家命尽 = 负 |
| F6 | HUD 与计分 | 显示得分、剩余命数、剩余敌人数；胜利/失败画面 |

### 2.2 范围外（Out of Scope，MVP 不做）

多关卡与难度递进 / 道具系统 / 本地存档 / 本地双人与联机 / 移动端触屏 / 地图编辑器 / 草丛・河流・冰面等扩展地形 / 音效与音乐（TBD-3 决议）。

## 3. 核心玩法规则

### 3.1 地图

- 格子制，尺寸 13×13 逻辑格〔默认，经典制式〕
- 地形元素：**砖墙**（可破坏，破坏粒度为 **1/4 子块**——每格砖分 4 个子块，子弹摧毁命中侧的子块，经典制式）、**钢墙**（不可破坏，挡子弹）、**空地**（可通行）、**基地**（鹰，1 格，被任何子弹命中即毁）
- 基地位于底边中央，周围有砖墙护圈〔默认〕

### 3.2 玩家

- 1 辆坦克，初始 **3 条命**〔默认〕，出生点在基地左侧固定位置〔默认〕
- 被敌方子弹命中 → 损失 1 命，原出生点重生（重生后短暂无敌 2 秒〔默认〕）
- 同屏玩家子弹最多 **1 发**〔默认，经典制式〕

### 3.3 敌人

- 敌人总数 **10 辆**〔默认〕，同屏最多 **4 辆**〔默认〕，从顶部 3 个固定出生点轮流出生〔默认〕
- 三种类型：

| 类型 | 特征 | 耐久 | 分值〔默认〕 |
|------|------|------|------|
| 普通 | 基准速度 | 1 发 | 100 |
| 快速 | 移动速度 ×1.5 | 1 发 | 200 |
| 装甲 | 基准速度 | 3 发 | 400 |

- 敌人 AI：随机巡逻 + 周期性射击，无寻路要求〔默认，MVP 不做智能寻路〕
- 敌人子弹不互相伤害敌人〔默认，经典制式〕

### 3.4 操作

- 移动：方向键 与 WASD 双支持〔默认〕
- 射击：空格 或 J〔默认〕
- 暂停：P 键切换暂停/恢复，暂停时所有实体冻结（TBD-1 决议：要）

### 3.5 子弹规则

- 玩家子弹与敌方子弹相撞 → **双双相消**（经典制式，G1 评审拍板）
- 敌方子弹之间互不影响（穿透）〔默认〕；敌方子弹不伤害敌方坦克（见 §3.3）

### 3.6 胜负与计分

- **胜利**：10 辆敌人全部被消灭
- **失败**：基地被任意子弹击毁，或玩家命数归零
- 计分：按 3.3 表，仅击毁敌人得分；胜利/失败画面显示最终得分，提供「重新开始」

## 4. 非功能约束

| # | 约束 |
|---|------|
| N1 | 桌面 Chrome / Edge / Safari 最新版可运行 |
| N2 | 60fps 流畅（普通办公机标准） |
| N3 | 纯静态前端，无后端、无账号体系；静态托管即可玩 |
| N4 | 代码遵循 agent-dev-standard（中文禁入代码字符串 / 魔法值常量化 / 状态用 enum） |
| N5 | 视觉采用程序化绘制（Canvas 几何图形），零外部素材依赖（TBD-2 决议） |

## 5. 验收条件（AC — 测试计划的推导基线）

| AC | 条件 |
|----|------|
| AC-1 | 玩家可用键盘四向移动，不能穿越砖墙/钢墙/边界/其他坦克 |
| AC-2 | 玩家射击：子弹摧毁命中侧的砖墙子块（1/4 粒度）；钢墙挡下子弹且不损毁 |
| AC-3 | 敌人按规则出生（总数 10 / 同屏 ≤4 / 顶部出生点），自动移动与射击 |
| AC-4 | 三种敌人类型的速度/耐久/分值有可观察区分 |
| AC-5 | 玩家被命中减 1 命并原点重生（带短暂无敌）；命尽 → 失败 |
| AC-6 | 基地被任意子弹命中 → 立即失败画面 |
| AC-7 | 敌人全灭 → 胜利画面；画面含最终得分与重新开始入口 |
| AC-8 | HUD 实时显示得分 / 剩余命 / 剩余敌人数 |
| AC-9 | 最新桌面 Chrome 全程 60fps 无可感卡顿 |
| AC-10 | 纯静态部署（本地 file:// 或任意静态服务器）可完整游玩 |
| AC-11 | P 键可暂停/恢复；暂停期间所有实体（坦克/子弹/出生计时）冻结 |
| AC-12 | 玩家子弹与敌方子弹相撞双双消失；敌方子弹之间互相穿透 |
