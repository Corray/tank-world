## 1. 项目定位

桌面浏览器端的经典坦克大战（Battle City 风格）游戏。玩家用键盘操控坦克，在格子地图中消灭全部敌方坦克并保卫基地。

> **定位裁定（2026-06-05 拍板，v5）**：本项目同时是 **agent-dev-standard 流程实验场**——首要目的为压测工作流，产品体验类人工验证不在验收范围（验证债 P-20260605-88ee 据此 dismissed）。验收口径以机器可验 AC 为准；若定位将来变更回产品，该裁定与验证债同步复议。

## 3. 核心玩法规则

### 3.1 地图

- 格子制，尺寸 13×13 逻辑格〔默认，经典制式〕
- 地形元素：**砖墙**（可破坏，破坏粒度为 **1/4 子块**——每格砖分 4 个子块，子弹摧毁命中侧的子块，经典制式）、**钢墙**（不可破坏，挡子弹）、**空地**（可通行）、**基地**（鹰，1 格，被任何子弹命中即毁）
- 基地位于底边中央，周围有砖墙护圈〔默认〕

### 3.2 玩家

- 1 辆坦克，初始 **3 条命**〔默认〕，出生点在基地左侧固定位置〔默认〕<!-- 已被取代（R4 双层护圈/R5 双人）：现行出生点 P1=(12,2)、P2=(12,10)，见数据模型 §11/§31（F-SPEC-0643 标注） -->
- 被敌方子弹命中 → 损失 1 命，原出生点重生（重生后短暂无敌 2 秒〔默认〕）
- 同屏玩家子弹最多 **1 发**〔默认，经典制式〕<!-- 已被 v2 §3.8 部分取代：火力道具生效期间上限 2 发（AC-18）；R5 起上限为 per-player（§3.17）（F-SPEC-5c55 标注） -->

### 3.3 敌人

- 敌人总数 **10 辆**〔默认〕，同屏最多 **4 辆**〔默认〕，从顶部 3 个固定出生点轮流出生〔默认〕
- 三种类型：

| 类型 | 特征 | 耐久 | 分值〔默认〕 |
|------|------|------|------|
| 普通 | 基准速度 | 1 发 | 100 |
| 快速 | 移动速度 ×1.5 | 1 发 | 200 |
| 装甲 | 基准速度 | 3 发 | 400 |

- 敌人 AI：随机巡逻 + 周期性射击，无寻路要求〔默认，MVP 不做智能寻路〕
- 敌人子弹不互相伤害敌人〔默认，经典制式〕

### 3.4 操作

- 移动：方向键 与 WASD 双支持〔默认〕
- 射击：空格 或 J〔默认〕
- 暂停：P 键切换暂停/恢复，暂停时所有实体冻结（TBD-1 决议：要）

### 3.5 子弹规则

- 玩家子弹与敌方子弹相撞 → **双双相消**（经典制式，G1 评审拍板）
- 敌方子弹之间互不影响（穿透）〔默认〕；敌方子弹不伤害敌方坦克（见 §3.3）

### 3.6 胜负与计分

- **胜利**：10 辆敌人全部被消灭
- **失败**：基地被任意子弹击毁，或玩家命数归零
- 计分：按 3.3 表，仅击毁敌人得分；胜利/失败画面显示最终得分，提供「重新开始」

### 3.7 关卡系统（R2 / F8）

- **3 个关卡**：地图布局各不相同（设计约束见数据模型）；敌人构成递进〔默认〕：

| 关 | 敌人总数 | 构成（普/快/装甲） | 出生间隔〔默认〕 |
|----|---------|------------------|----------------|
| L1 | 10 | 4 / 3 / 3 | 3.0s |
| L2 | 14 | 5 / 5 / 4 | 2.5s |
| L3 | 18 | 6 / 6 / 6 | 2.0s |

- **过关**：本关敌人全灭 → 过关画面（本关得分 + 累计得分 + 进入下一关）；L3 过关 → 全通画面（总分 + 重新开始）
- **本关失败**：基地毁或命尽 → 失败画面 → **从当前关重试**（不回 L1）
- **重试规则（OPEN-3 决议）**：本关得分清零、之前关卡累计保留；命数重置为 3；地图与道具状态全部重置
- **命数跨关保留**〔默认〕：过关不补命，全通即一条 run（重试才重置）

### 3.8 道具系统（R2 / F9）

| 道具 | 效果 | 时限 |
|------|------|------|
| 护盾 | 玩家无敌（同重生无敌语义，C6 走无敌分支） | 10s〔默认〕 |
| 火力 | 同屏子弹上限 1→2 发（OPEN-2 决议：不破钢墙） | 持续：过关保留、死亡丢失〔默认〕 |
| 炸弹 | 拾取瞬间场上敌人全部即死；**不计分**〔默认，高分必须枪杀〕 | 即时 |

- **掉落规则**：每关第 4 / 8 / 12 个出生的敌人为携带者（总数不足则有几个算几个，L1 仅 4/8），携带者**闪烁标识**；被击毁时道具落于死亡点，永驻至拾取或本关结束〔默认〕
- **道具类型序列**〔默认〕：护盾 → 火力 → 炸弹 固定循环（利于测试与平衡，不随机）
- 同类道具重复拾取：护盾刷新时限；火力不叠加（仍 2 发）〔默认〕

### 3.9 难度平衡（R2 / F7）

- **基地护圈**：双层砖圈（OPEN-1 决议），具体格位由数据模型定
- **AI 威胁分层**〔默认概率值，手感可调〕：
  - BASIC：纯随机巡逻（现状）
  - FAST：转向决策时 50% 概率选取朝向基地的方向（压迫基地）
  - ARMORED：转向决策时 50% 概率选取朝向玩家的方向（压迫玩家）
- **射击间隔**：1.2s → 1.8s 基准〔默认，手感调〕
- **平衡验收**：普通玩家首局存活 ≥ 60s；连玩 3 局至少赢 1 局（PRD §4 指标）
- 手感调参轮次显式记录于实现总结，最终值回写本文档与 constants

### 3.10 最高分存档（R2 / F10）

- `localStorage` 持久化两档〔默认 key：`tank-world.best-total` / `tank-world.best-level`〕：
  - **全通总分**：仅 L3 全通时参与比较
  - **单关最高分**：任意单关结算分参与比较
- READY 画面与过关/失败/全通画面均展示对应最高分；刷新页面不丢失
- 无账号体系；清浏览器数据即清零（接受）

### 3.11 打击感特效（R3 / F11）

全部程序化绘制（N5 延续），不引入图片素材：

| 事件 | 特效 | 时长〔默认〕 |
|------|------|------|
| 敌坦克击毁 | 扩散圆环 + 碎片粒子 | 400ms |
| 玩家死亡 | 同上（颜色区分） | 400ms |
| 基地被毁 | 大型爆炸（约 2 格半径），随后进失败画面 | 800ms |
| 子弹命中砖/钢 | 小型火花 | 150ms |
| 击杀计分 | `+分值` 飘字上浮渐隐于击毁点 | 600ms |
| 玩家受击 | 全屏白闪〔默认，不做画面震动——防晕且避免 Canvas 位移露底〕 | ≤200ms |

- 特效为纯视觉实体，不参与任何碰撞/逻辑判定；暂停时冻结
- 特效峰值下维持 60fps（AC-31）

### 3.12 程序化音效（R3 / F12）

- **Web Audio 程序化合成**（OPEN-R3-1 决议）：零素材文件，产物保持单文件
- 8 类事件音：射击 / 命中砖 / 命中钢 / 击毁敌人 / 玩家死亡 / 道具拾取 / 过关 / 失败——彼此有可辨识区分度
- **M 键静音开关**，状态持久化 localStorage（`tank-world.muted`〔默认 key〕），HUD 显示当前状态
- AudioContext 在首次用户按键时 resume（浏览器 autoplay 策略）；READY 画面前无声音
- 音质兜底：若评审/实测认为合成质感不可接受，切换 CC0 采样 base64 内联路线（PRD §5 备选，需重新评审体积影响）

### 3.13 无尽模式（R3 / F13）

- **入口**：L3 清场仍进 GAME_COMPLETE 画面（全通结算照旧），新增「继续无尽」入口（OPEN-R3-2 决议）
- **无尽关（L4, L5, …）规则**〔默认公式，数据模型定稿〕：
  - 地图：三张图按 L1→L2→L3 顺序轮换
  - 敌人总数：18 + 2×(关号−3)
  - 出生间隔：2000 − 100×(关号−3) ms，下限 1200ms
  - 装甲占比：逐关递增，封顶 50%；其余按快速/普通均分
- **死亡即结算**：无尽关失败无重试，进入无尽结算画面（本次无尽总分 + best-endless + R 开全新 run）
- **计分档位**：无尽分数（从 L4 起累计）写入独立 `best-endless` 档；**best-total 仅记 3 关全通，不受无尽污染**
- 无尽期间 HUD 显示 `LEVEL n/∞`；过关画面照常（分数入账逻辑沿用 §3.7）
- 命数：进入无尽时不重置（带着全通余命挑战）〔默认〕；无尽过关不补命

### 3.14 扩展地形（R4 / F14）

| 地形 | 移动 | 子弹 | 渲染 | 可破坏 |
|------|------|------|------|--------|
| 草丛 BUSH | 通行 | 穿透 | **遮挡所有坦克**（草在坦克之上；对称规则，OPEN-R4-2 决议）；子弹不被遮挡（轨迹暴露位置） | 否 |
| 河流 WATER | **阻挡坦克** | **穿透** | 普通层 | 否 |
| 冰面 ICE | 通行 + **全惯性滑行**（OPEN-R4-1 决议） | 穿透（同空地） | 普通层 | 否 |

- **冰面惯性**〔默认参数，手感调〕：松键后沿原方向继续滑行，速度按摩擦系数衰减（约 0.5s 滑停）；按键转向立即生效但速度矢量渐变；滑行受碰撞约束（不穿墙不出界，AC-34）
- AI 敌人视河流为阻挡（受阻即转向决策，不卡死）；AI 在冰面同样受惯性
- 道具不会掉落在河流格上〔默认：携带者死于河上时道具落到最近可通行格〕——实际上坦克不能进河，死亡点必不在河上，此条为防御性声明
- 基地护圈结构不变（双层砖不被新地形替换）

### 3.15 无尽地形变体（R4 / F15）

- 无尽轮换图（L1/L2/L3 布局骨架）按**确定性规则**叠加地形变体：同关号永远生成同一变体（可测、可复现）
- 变体强度〔默认〕：每图替换 6~10 个空地格为草/河/冰组合；不覆盖出生点、基地护圈、护圈通路
- L1~L3 正常关也纳入新地形（地图改版），变体仅作用于无尽

### 3.16 成就系统（R4 / F16）

8 个全做（OPEN-R4-3 决议；PRD 原「单局命中率」项换为「累计百杀」——命中率需全弹道统计，性价比低）：

| ID | 成就 | 触发 |
|----|------|------|
| A1 | FIRST_BLOOD | 首次击毁敌人 |
| A2 | NO_DEATH_LEVEL | 一关内未损失命数过关 |
| A3 | FULL_CLEAR | 三关全通 |
| A4 | ENDLESS_8 | 无尽达到 L8 |
| A5 | COLLECTOR | 单局（一条 run）集齐三种道具 |
| A6 | DEMOLITION | 一关内拆光全部砖墙（**最后一击须为玩家子弹**——#14 PM 决策 2026-06-05 澄清主体） |
| A7 | PURIST | 全程不拾取任何道具完成全通 |
| A8 | CENTURION | 累计击毁 100 名敌人（跨局累计） |

- 达成即游戏内 toast 提示（顶部横幅，约 2.5s〔默认〕，暂停冻结同特效规则）
- localStorage 持久化（`tank-world.achievements` + 累计杀数 `tank-world.kills`〔默认 key〕）；不可重复触发
- READY 画面显示「已达成 n/8」+ HUD 侧栏查看明细〔默认：HUD 下方列表，达成项亮色〕
- 不做云端、不做隐藏成就、不做奖励加成（纯荣誉）

### 3.17 本地双人合作（R5 / F17）

- **模式选择**：READY 画面按 **2** 进入 2P；其余操作键开局 = 1P（兼容既有行为）
- **键位**（仅 2P 局生效；1P 局键位不变）：P1 = WASD + J；P2 = 方向键 + Enter；P/R/M 全局键不变
- **出生点**：P1 (12,2)（现位），P2 (12,10)〔默认，基地右侧对称位〕
- **命数与失败**：各自 3 命独立重生/无敌；一人命尽另一人继续；**双双命尽或基地毁 → DEFEAT**；重试当前关双人均复活满命
- **计分**：各自累计各自显示；结算与入档取**两人合计**，单设 `best-coop` 档〔默认〕，单人三档不受污染
- **重试时个人分随本关得分一并清零**（#13 PM 决策 2026-06-05：不变量 sum(个人分) ≤ 累计+本关）
- **玩家间交互**：互相阻挡不互伤（C11 扩展）；**友军子弹互相穿透**〔默认，不做经典 stun〕（新增 C17）
- **道具**：拾取者独享效果（护盾/双发归个人；炸弹仍全场）；发射权上限 per-player 独立计
- **AI**：ARMORED 偏好压**最近的存活玩家**；敌弹对两玩家均有效（C6 扩展）
- **边界（收窄决议）**：2P 局**成就不触发**；GAME_COMPLETE 画面**无「继续无尽」入口**（2P 无尽留 R6）<!-- 已被 v6 §3.19/§3.20 改判撤销（R7，原决议动机=控 R5 重构面已消失） -->
- **结构决议**：`world.player` → `world.players: PlayerTank[]` 彻底复数化（OPEN-R5-3），不留 player2 兼容字段

### 3.21 双人对战 VS（R8 / F21）

首个**对抗阵营**模式（此前 SOLO/COOP 均为 PvE 同阵营）；SOLO/COOP 全行为零回归是硬指标。

- **入口**：READY 画面按 **3** 进入 VERSUS；按 1 或其余操作键 = SOLO、按 2 = COOP（既有行为不回归）。`GameMode` 增 `VERSUS` 值。
- **战场（纯 PvP）**：VS 专用对称地图（上下镜像），**无 NPC 敌人**（enemy 出生调度在 VERSUS 下完全不激活）。中线开阔利于交火。
- **双基地**：P1 基地底边中央（现位），P2 基地顶边中央〔默认，对称镜像位〕；各带砖护圈（结构沿用 §3.9 双层砖圈）。
- **友军火力反转（核心机制，C17 在 VERSUS 反转）**：
  - 玩家子弹命中**对方**玩家坦克（`bullet.playerId !== target.id`）→ 造成伤害（损 1 命，原点重生）
  - 命中**自身**（`playerId === target.id`）→ 穿透（不自伤）
  - SOLO/COOP 维持「玩家子弹穿透所有玩家」不变（零回归）
  - 重生无敌期 / 护盾期对**对手**子弹同样免伤〔默认，不为对手开后门〕
- **胜负（双条件，先达者胜，OPEN-R8-1 决议）**：
  - 摧毁对方基地（走 C3 基地摧毁，归属到防守方→对方胜）**或** 打光对方命数（命尽方负）
  - 各 **3 命**〔默认〕
- **回合制 best-of-3（OPEN-R8-4 决议）**：3 局 2 胜；每局结束进**回合间场**（复用 LEVEL_CLEAR 间场骨架，显示当前比分 X:Y）；**每局开始**双方满命、地图重置、道具清空（复用 loadLevel 重置）；先胜 **2** 局〔默认〕者进 VS 总结算。
- **道具（OPEN-R8-3 决议）**：保留**护盾 / 双发**（个人化归拾取者，效果沿用 §3.8）；**炸弹去除**（PvP 下「全场即死」语义错乱）。
  - **新道具来源**（VS 无 NPC 携带者）〔默认〕：竞技场中线对称中立点每 **~12s** 刷新一个，护盾/双发交替，先到先得（具体点位/周期由数据模型定，手感可调）。
- **结算**：VS 总结算画面显示胜者（`P1 WINS` / `P2 WINS`）+ 双方击杀数 / 剩余命 + 最终比分 + R 重开。
- **存档（OPEN-R8-5 决议）**：VS **不写任何存档档位**；现有六档（best-total/level/endless/coop/coop-endless/muted）零污染。
- **成就**：VS 局成就不触发（8 成就语义与 PvP 阵营对抗不兼容；NPC 混战 VS 与成就接入留 R9）。
- **暂停**：任一玩家按 P 全局暂停〔默认，沿用全局键〕。
- **方法载体**：G3 产出「模式分叉清单 v3」——逐写入点列举三态（SOLO/COOP/VERSUS）行为，行数 = grep 命中数（AC-59，延续 AC-51）。
