# R4 实现总结（L2）

**日期：** 2026-06-05 / **分支：** feature/r4-terrain-achievements / **关联：** PRD R4（accepted）、共识 v4、数据模型 §23~28

## 背景

R4 主题「大地的规则」：三种新地形（草丛/河流/冰面）补战术深度、无尽地图确定性变体补多样性、8 个成就补第三目标轴。验证债（4 项人工终验）经用户两次拍板顺延，已落 P-20260605-88ee 显式风险接受。

## 做了什么

- **W1 地形**：Terrain 枚举 +3；三关地图改版（每关含全部新地形且保持基线结构断言）；水/冰贴图 + 草丛**上层遮挡渲染**（层序：地形→坦克→草→特效→覆盖层）
- **W2 冰面惯性**：moveTank 重构为 translate/refreshSlide/applySlide 三件套——主动移动刷新动量、无输入帧衰减滑行（0.92/步 ≈0.5s 滑停）、四条清零路径（滑停/撞墙/离冰/换关重生）全部显式
- **W3 无尽变体**：每图人工标注 12 个安全槽位 + LCG 确定性选取（6+level%5 个）+ 草→河→冰循环填充；同关号永远同变体
- **W4 成就**：8 触发钩子分布在 combat/powerup/judge/loadLevel 四处；unlock 幂等（storage 无模块缓存，测试隔离靠 mock store）；toast 复用 effects 生命周期；READY/HUD 进度与明细

## 关键决策与思考

1. **C15「子弹穿透新地形」零代码实现**：advanceBullet 只认砖/钢/基地，新地形天然穿透——白名单式碰撞设计让扩展免费
2. **惯性从 moveTank 拆出 translate**：facing 变更（主动）与位移（被动滑行）解耦，滑行不改朝向——炮口方向与滑行方向可以分离，正是冰面的战术趣味来源
3. **变体安全用人工槽位表而非通路分析**：12 格×3 图的标注成本一次性，换来零算法风险——「确定性优先于聪明」
4. **成就无模块缓存**：每次读 storage——代价微（条目少），换来测试零状态泄漏与刷新天然恢复
5. **AI 在冰上对称受惯性**但因 AI 每帧主动移动，惯性主要表现为 slide 字段维护——契约由 T-TER-9 锁定，行为差异留实战观察

## 预判失误记录

G1 门禁「基线零修订」漏判 1 处：T-EN-2 的**引用相等**断言（`layout === LEVELS[0].layout`）被变体克隆合法打破。修订独立 commit 44b6c40。教训：预判基线冲击时要扫「断言强度」（引用相等 vs 结构相等），不只扫语义。
