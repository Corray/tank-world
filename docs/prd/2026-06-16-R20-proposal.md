## 1. 问题陈述

1. **R17 引入的真实回归**：战役扩到 L5（26 敌）后，无尽仍从 `18 + STEP×k` 起（L6=20 敌 < L5=26），且出生间隔从 2000 基数起（L6=1900ms > L5=1600ms）——**无尽比战役末关更轻，难度倒挂**。
2. **硬编码债**：endlessConfig 的 `18`（旧 L3 敌数）/ `2000`（旧 L3 间隔）是「战役末关」的硬编码快照——战役一改就失真（R17 即失真）。应**派生 LEVELS 末关**（呼应 R17「派生 vs 硬编码」主题）。

## 2. 需求清单

### F-R20-1 endless 基数派生（P0，修回落 + 去魔法值）

- endlessConfig 的 total 基数 `18` → **派生** `LEVELS 末关敌人总数`（当前 L5=26）
- spawnInterval 基数 `2000` → **派生** `LEVELS 末关 spawnIntervalMs`（当前 L5=1600）
- 效果：无尽 L6（k=1）= 26+STEP 敌 / 1600−STEP_MS 间隔 → **≥ 战役末关，递增不回落**
- 战役关数/难度再变时 endless 基数自动跟随（消除硬编码快照失真）

### F-R20-2 无回落不变量（P0）

- `endlessConfig(LEVEL_COUNT+1)` 敌人总数 ≥ 战役末关总数（机器可验不变量）
- 曲线斜率（ENDLESS_TOTAL_STEP / INTERVAL_STEP / ARMOR_*）不变——仅平移基数

## 3. 明确不做（本轮）

- 纯体验数值调参（NPC 护圈 / 铲冻时长 / SUMMONER 数值 / Boss HP）——无真实 bug，不验收平衡，不 churn
- endless 曲线斜率重设计（仅修基数回落）
- ENDLESS_8 阈值（保字面 8）

## 4. 成功指标

- 无尽 L6 总数 ≥ L5（无回落不变量成立）；基数派生 LEVELS 末关（无 18/2000 硬编码）
- 既有 315 测试基线冲击全部在预判清单内（endless 值测试修正性 churn）；tsc 净
