## 1. 问题陈述

1. **难度固定**：所有玩家面对同一敌人节奏，新手过难/老手过易，无适配维度。
2. **正交横向系统**：难度是与「模式（SOLO/COOP/VS/MELEE/WAVE）」正交的维度——任一模式都可叠加难度缩放。
3. **零回归锚复用**：NORMAL=1.0 全维度缩放，既有测试零回归（同 R18 首杀×1 / R17 派生零改的设计锚思路）。

## 2. 需求清单

### F-R19-1 难度档位（P0）

- `types` 增 `enum Difficulty { EASY, NORMAL, HARD }`；`World.difficulty` 默认 `NORMAL`
- 穷举映射（家族自查）：缩放因子用 `Record<Difficulty, number>` 表，新 enum 值须三档齐全

### F-R19-2 缩放维度（P0，OPEN-R19-2 决议）

- `constants`：`DIFFICULTY_SPEED_FACTOR = {EASY:0.85, NORMAL:1.0, HARD:1.2}`、`DIFFICULTY_INTERVAL_FACTOR = {EASY:1.3, NORMAL:1.0, HARD:0.75}`
- 应用点 **trySpawnEnemy**（单点）：`spawnCooldownMs = spawnIntervalMs × INTERVAL_FACTOR[difficulty]`；新生敌人 `enemy.speed ×= SPEED_FACTOR[difficulty]`
- **NORMAL=1.0 双维 → 零回归锚**：createEnemy 保持纯（缩放在 spawn 点，不改 createEnemy 签名），既有敌速/出生节奏测试零冲击

### F-R19-3 切换入口（P0，OPEN-R19-3 决议）

- `input` 按 **D** → onCycleDifficulty；`game.cycleDifficulty`：**仅 READY 可改**（PLAYING 中锁定，避免局内变难度），EASY→NORMAL→HARD→EASY 循环
- main 接线

### F-R19-4 HUD 显示（P1）

- HUD 显示当前难度 `DIFF: NORMAL`；READY overlay 加 `D: difficulty` 提示

## 3. 明确不做（本轮）

- 难度影响 Boss HP / 道具掉率 / 计分倍率（仅敌速+出生间隔；避免影响面扩散）
- 局内动态难度（DDA）（仅 READY 静态选择）
- 难度持久化存档（每次会话默认 NORMAL）
- per-难度 独立最高分档（档位已八个，不再扩）

## 4. 成功指标

- 默认 NORMAL；D 在 READY 循环三档、PLAYING 锁定
- HARD 出生更快（interval<1）+ 敌速更高（speed>1）；EASY 反之
- **NORMAL 缩放=1.0 → 既有 308 测试零回归**；tsc 净
- 穷举因子表三档齐全
