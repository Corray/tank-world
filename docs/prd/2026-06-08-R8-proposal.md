## 1. 问题陈述

1. **玩法维度缺口**：现有所有模式（SOLO/COOP + 无尽）均为 **PvE 同阵营协作**——玩家从未互为敌对。对战是经典坦克大战的标志性玩法，缺它则玩法谱系不完整。
2. **结构性挑战（最大价值点）**：VERSUS 是首个引入**对抗阵营**的模式。现有每个 mode 分叉点都隐含「玩家同阵营」假设（友军子弹穿透、合计计分、团队成就）。VERSUS 加入会激活一批**未预见的分叉点**——正是 R7「写入点级分叉清单」方法的第三轮、也是最强压力测试（前两轮 SOLO/COOP 同为 PvE，缺对抗维度样本）。
3. **基础设施已就位**：R5 为计分归属在 `Bullet` 上加的 `playerId?: 1|2` 字段，恰好是 VS 友军火力归属的现成基础——零额外子弹结构重构。

## 2. 需求清单

### F-R8-1 VERSUS 模式入口（P0）

- `GameMode` 增 `VERSUS` 值；READY 画面按 **3** 进入 VS（按 1/其他=SOLO、2=COOP 既有行为零回归）
- 复用现有 mode 分发骨架（main/world/update/hud 的 `mode ===` 分叉点）

### F-R8-2 友军火力反转（P0，核心机制）

- C17 在 VERSUS 下**反转**：玩家子弹命中**对方**玩家坦克 → 造成伤害（SOLO/COOP 维持穿透不互伤，零回归）
- 归属判据：`bullet.owner === PLAYER && bullet.playerId !== target.id` → 命中互伤；`playerId === target.id` → 穿透自身
- 重生无敌期（`invincibleUntil` / `shieldUntil`）对对手子弹同样生效（沿用现有无敌语义，不为对手开后门）

### F-R8-3 双条件胜负（P0，OPEN-R8-1 决议=a）

- **双基地对称**：P1 基地底边中央（现位），P2 基地顶边中央（对称位）；各带砖护圈
- **胜负条件（先达者胜）**：摧毁对方基地 **或** 打光对方命数（各 3 命）
- 复用现有机器：基地摧毁走 C3、命数耗尽走现有重生→命尽逻辑，仅需「归属到某一方 + 翻转为对方胜」

### F-R8-4 纯 PvP 竞技场（P0，OPEN-R8-2 决议=纯 PvP）

- VS 专用对称地图，**无 NPC 敌人**（enemy 模块在 VS 下完全不激活）
- 布局对称镜像（上下翻转）；中线区域开阔利于交火，双基地各有护圈

### F-R8-5 VS 结算与回合（P0 结算 + P1 回合）

- **回合制（OPEN-R8-4 决议=best-of-3）**：3 局 2 胜；每局结束进回合间场（复用 LEVEL_CLEAR 间场骨架，显示当前比分 X:Y），先胜 2 局者进 VS 总结算
- **结算画面**：显示胜者（P1/P2 WINS）+ 双方击杀数/剩余命 + 比分 + R 重开
- VS **不写任何存档档位**（OPEN-R8-5 PM 默认：对战即时性，保持现有六档不污染）

### F-R8-6 VS 道具（P1，OPEN-R8-3 决议=护盾+双发去炸弹）

- 保留**护盾 / 双发**（个人化归拾取者，沿用 §3.8 效果）；**炸弹去除**（「全场即死」在 PvP 下语义错乱）
- **新道具来源**（VS 无 NPC 携带者）〔默认〕：竞技场中立点定时刷新，先到先得（具体点位/周期见数据模型）

### F-R8-7 写入点级分叉清单 v3（P0 方法载体，G3 产物）

- G3 产出「模式分叉清单 v3」：grep `GameMode`/`mode ===` 全命中 + C17 友军火力点 + 基地/命数归属点 + 道具刷新点，逐行标注 SOLO/COOP/**VERSUS** 三态行为与测试归属
- 验收判据：清单行数 = grep 命中数（±0），延续 AC-51 机器可验

## 3. 明确不做（本轮）

- **NPC 混战**（V8 → R9 候选）：叠两套胜负逻辑，偏离纯对战
- **VS 战绩持久化**（V9）：即时性体验，存档性价比低，扩大档位隔离测试面
- **成就接入 VS**（V10）：8 成就语义（守基地/无尽/拆墙/团队）与 PvP 阵营对抗根本不兼容
- 战役新关卡 / 随机地图 / 移动端 / 联机 / 编辑器

## 4. 成功指标

- VERSUS 全链路绿：入口→对战→回合切换→双条件胜负→结算
- 友军火力反转正确：对手子弹互伤、自身子弹穿透、无敌期不被白嫖（三态测试）
- **SOLO/COOP 行为零回归**（VERSUS 是纯增量，现有 191 测试不许变红）
- 分叉清单 v3 行数 = grep 命中数（机器可验，第三轮方法实证补给 #33）
