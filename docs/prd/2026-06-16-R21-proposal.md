## 1. 问题陈述

1. **难度每次会话重置**：R19 难度选择是局内/会话内的，刷新页面回 NORMAL。玩家每次都要重选——体验断点。
2. **localStorage 持久化是现成范式**：muted/八档最高分均已 localStorage 持久（fail-silent），难度同款接入即可。

## 2. 需求清单

### F-R21-1 难度持久化（P0）

- `constants` 增 `KEY_DIFFICULTY = 'tank-world.difficulty'`
- `storage` 增 `getDifficulty()`/`setDifficulty(d)`（fail-silent，非法/空值 → NORMAL，同 getMutedPref 范式）
- `createWorld` difficulty 初始化由固定 NORMAL → **读 `getDifficulty()`**（每个新世界含 restartToReady 后的世界都恢复持久难度）
- `cycleDifficulty` 切换后 **`setDifficulty` 写入**

### F-R21-2 零回归（P0）

- getDifficulty fail-silent：localStorage 空/缺失/非法 → NORMAL → 既有 createWorld().difficulty===NORMAL 测试零回归
- createWorld 保持「无 localStorage 环境安全」（try/catch 降级）

## 3. 明确不做（本轮）

- 难度影响计分/档位（R19 已定不做）
- per-难度 独立最高分档（档位不扩）
- UI 难度选择菜单（沿用 T 键循环）

## 4. 成功指标

- setDifficulty→getDifficulty round-trip；createWorld 恢复持久难度；cycleDifficulty 写入
- localStorage 空/非法 → NORMAL（fail-silent）；既有 316 测试零回归；tsc 净
