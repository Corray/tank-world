## 1. 问题陈述

1. **验证债**：平衡/手感/音效质感全靠代理指标与单测撑着，4 项人工挂账（M-R2-1/2、音色耳测、特效主观）未清。
2. **地形单一**：三种地形（砖/钢/空）的战术深度已被三轮玩法吃尽；无尽模式的三图轮换重复感最先暴露。

## 2. 需求清单

### F-R4-0 终验回补 + 调参轮（P0 前置，非功能开发）

**内容**：PM（用户本人）完成一次 15 分钟游玩，覆盖：首局存活 ≥60s（M-R2-1）/ 全通时长（M-R2-2）/ 音效耳测（不达标触发采样路线）/ 特效主观手感。结论回填各测试计划 §5；不达标项在 R4 期间作为调参插入项处理。

**为什么是 P0 前置**：地形（尤其冰面）会显著改变操控手感——基线手感未确认就叠加新变量，调参将无法归因。

### F-R4-1 扩展地形×3（P0）

**用户故事**：作为玩家，我希望地图上有藏身处、天堑和危险地带，走位决策比「躲在砖后」更丰富。

| 地形 | 规则（经典制式） |
|------|------|
| 草丛 BUSH | 不挡移动不挡子弹；坦克进入后被视觉遮挡（草渲染在坦克之上）；不可破坏 |
| 河流 WATER | 挡坦克、**不挡子弹**；不可破坏 |
| 冰面 ICE | 可通行；坦克在其上有滑行惯性（松键后滑行衰减）`[OPEN-R4-1: 惯性是手感风险最大项，可降级为仅延迟停止]` |

- 三关地图改版纳入新地形 + 无尽轮换图生成地形变体（同布局骨架、地形点位变化）
- 碰撞矩阵增量草案：坦克×河=阻挡 / 子弹×河=穿透 / 坦克×冰=滑行 / 草=纯渲染层

**验收草案**：三种地形行为各自可观察验证；AI 敌人不会卡死在河边；冰面滑行不导致穿墙。

### F-R4-2 成就系统（P1）

**用户故事**：作为玩家，我希望有刷分之外的挑战目标。

- 轻量 8 个〔候选清单，共识定稿〕：首次击杀 / 单局百发命中 50+ / 无伤过一关 / 全通 / 无尽达 L8 / 单局集齐三种道具 / 拆光一关全部砖 / 一局不用道具全通
- localStorage 持久化；READY 画面入口查看；达成时游戏内 toast 提示
- 不做云端、不做进度百分比墙

**验收草案**：每个成就可达成、达成即提示、刷新不丢、不可重复触发。

## 3. 明确不做（本轮）

## 4. 成功指标

- 验证债清零：4 项挂账全部有结论记录
- 地形：每种地形在实战中产生可观察的战术行为差异（藏草丛伏击 / 隔河对射 / 冰面失控）
- 无尽：同一轮换图的地形变体肉眼可辨
