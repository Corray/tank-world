## 1. 问题陈述

1. **道具面不全**：现有 SHIELD / DOUBLE_FIRE / BOMB / STAR 均为「自强/清场」向，缺经典 Battle City 的防御（铲子）、控场（冻结）、续航（加命）三件。
2. **净新机制可控**：引入「定时全局效果」（铲子的地形临时改写+回退、冻结的全局定身时钟）——首个非 per-player 的计时效果，但不触碰胜负/碰撞核心。
3. **方法自我应用第三证**：扩 `PowerupType` + 改 `DROP_CYCLE`/`VS_DROP_CYCLE` 内容，将第三次击中「穷举映射/数据内容断言」家族（R10 事后被拦 → R11 事前预补 → R12 验证方法已内化）。G3 须 grep 断言两循环内容的既有测试列基线冲击清单。

## 2. 需求清单

### F-R12-1 三新道具类型（P0）

- `PowerupType` 增 `SHOVEL` / `FREEZE` / `LIFE`
- **穷举/数据内容全扫**（增量 7 教训）：`DROP_CYCLE`（powerup）、`VS_DROP_CYCLE`、render 道具图标分支、断言循环内容的既有测试（T-PWR-1 族 + T-VS-* 中立池断言）——G3 列全
- **成就影响面声明**：`COLLECTOR_TYPES` 维持 3（语义=「一局内拾 3 种不同道具」，3/7 比 3/4 更易达成属自然放宽，非回归）；不加新成就（ACHIEVEMENT_COUNT 维持 8）

### F-R12-2 SHOVEL 铲子（P0，OPEN-R12-2 决议=全恢复为砖）

- 拾取 → **对应基地护圈内层（紧邻基地一圈格位）变钢** `SHOVEL_MS`〔默认 15s〕
- 到期 → 护圈格**全恢复为砖**（含拾取前已被打掉的格——经典行为，兼具修墙价值）
- 归属：PvE 单基地即玩家基地；**VS/MELEE 加固拾取者己方基地**（攻防纵深）
- 重复拾取：刷新时限（同 SHIELD 语义）；双方各自拾取互不干扰（per-base 时钟）

### F-R12-3 FREEZE 冻结（P0，OPEN-R12-1 决议=仅冻 NPC）

- 拾取 → **全场存活 NPC（含 Boss）定身** `FREEZE_MS`〔默认 8s〕：不移动、不射击
- 冻结窗口内**新出生的 NPC 同样冻结**（全局 freezeUntil 时钟，非逐个标记）
- 重复拾取：刷新时限
- **仅作用 NPC**：VS（无 NPC）中立池不投放；MELEE 冻全场 NPC（不冻对方玩家）

### F-R12-4 LIFE 加命（P0，OPEN-R12-3 决议=无上限）

- 拾取 → **拾取者 `lives + 1`，无上限**；HUD 命数同步显示
- 7 道具一轮才出一次，节奏天然限流

### F-R12-5 投放池扩展（P0，OPEN-R12-4 决议=VS 仅加 SHOVEL）

- **PvE/MELEE 掉落循环 4→7**：护盾→双发→炸弹→星→**铲→冻→命**（新三件尾部追加，保留既有前缀最小化基线冲击）
- **VS 中立池 3→4**：护盾/双发/星/**铲**（FREEZE 无目标、LIFE 拖 best-of-3 节奏，均不入）
- MELEE 走 NPC 携带者掉落，天然沿用 PvE 7-cycle（零改）

### F-R12-6 定时效果生命周期（P0，核心约束）

| 重置点 | shovelUntil（per-base）/ freezeUntil（全局） |
|--------|------------------------------------------|
| loadLevel（过关/无尽下一关） | 清零（定时效果不跨关） |
| retryLevel | 清零 |
| setupVersus / setupMelee（每局） | 清零（不跨局） |

（对照 R10 重置点矩阵：STAR 升级是「loadLevel 故意持久」，本轮定时效果**全部不持久**——两类并存即「持久 vs 重置」维度的对照样本）

## 3. 明确不做（本轮）

- GRENADE / HELMET（与 BOMB / SHIELD 重复）
- GUN 直升满级（与 STAR 重叠，破坏 R10 升级曲线）
- BOAT 过水（地形交互复杂度高、收益窄）
- FREEZE 冻对方玩家（PvP 定身被动体验差，平衡争议大）
- 第 9 成就 / COLLECTOR_TYPES 上调（避免成就回归）
- Boss HP / NPC 护圈平衡调参（与道具轮无耦合，违背 PR 原子性，留后轮）

## 4. 成功指标

- 三新道具在 PvE/MELEE 7-cycle 正常掉落拾取；VS 中立池 4-cycle 含铲不含冻/命
- 铲子变钢/到期回砖、冻结全场定身（含窗口内新出生）、加命 HUD 同步，全部机器可验
- 定时效果不跨关不跨局（重置点矩阵全覆盖）
- **既有 249 测试零回归**；断言 DROP_CYCLE/VS_DROP_CYCLE 内容的基线修订在 G3 预判清单内（预判外修订 = 方法失效信号）
- tsc 干净；单文件体积增量可控
