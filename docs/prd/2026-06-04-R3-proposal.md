## 1. 问题陈述

1. **行为没有回响**：击毁敌人 = 方块消失，基地被炸 = 鹰变灰，玩家死亡 = 瞬移回出生点。所有关键事件零视听反馈，「打中了」的爽感完全缺失。
2. **全通即终点**：R2 给了 10-15 分钟的目标，打完 3 关后最高分体系就失去增长空间。

## 2. 需求清单

### F-R3-1 打击感特效包（P0）

**用户故事**：作为玩家，我希望击毁、爆炸、得分都有可见的反馈，操作有「回响」。

**需求点**（全部程序化绘制，N5 延续）：
- 坦克击毁爆炸动画（扩散圆环/碎片粒子，约 300-500ms）
- 基地被毁大爆炸（区别于坦克的更大特效）
- 子弹命中砖墙/钢墙的火花点缀
- 击杀计分飘字（+100/200/400 在击毁点上浮渐隐）
- 玩家被击中的受击反馈（短促白屏闪 或 画面微震，二选一由设计层定）

**验收草案**：每类事件均有可辨识特效；特效不遮挡操作判断；60fps 不掉。

### F-R3-2 程序化音效（P0）

**用户故事**：作为玩家，我希望射击和爆炸有声音，闭着眼能听出战况。

**需求点**：
- Web Audio **程序化合成**（零素材文件，不破单文件 file:// 约束）：射击 / 命中砖 / 命中钢 / 击毁敌人 / 玩家死亡 / 道具拾取 / 过关 / 失败 8 类
- M 键静音开关，状态入 localStorage；AudioContext 在首次按键时 resume（浏览器 autoplay 策略）
- `[OPEN-R3-1]` 合成音质有「廉价感」风险——备选路线：CC0 采样 base64 内联（体积 +30~80KB），拍板见 §5

**验收草案**：8 类事件有区分度；静音开关即时生效且持久化；file:// 直开仍可玩。

### F-R3-3 无尽模式（P1）

**用户故事**：作为玩家，我希望通关后还能继续打，挑战更高分。

**需求点**：
- L3 清场后进入无尽关（L4, L5, …）：地图从三张图轮换，敌人总数 +2/关、出生间隔 -100ms/关（下限 1200ms）、装甲比例递增
- 无尽关死亡 = run 结束（无重试），进入结算
- `[OPEN-R3-2]` 结算语义需拍板：无尽分数是否并入 best-total，还是单设 best-endless 档？GAME_COMPLETE（3 关全通结算）是否保留为显式节点？见 §5

**验收草案**：L4+ 难度可感知递增；无尽进度在 HUD 可见（LEVEL 4/∞）；最高分语义无歧义。

## 3. 明确不做（本轮）

扩展地形（R4 候选，配合无尽地图多样性再做）/ 本地双人 / 成就 / 移动端 / 联机 / 编辑器。

## 4. 成功指标

- 反馈层：录屏对比 R2，每个击毁事件有 ≥1 个视觉 + 1 个听觉反馈
- 无尽：PM 实测「再来一局」意愿相比 R2 不降；单 run 时长中位 ≥ R2 全通时长
- 性能：满屏特效 + 音效下仍 60fps（AC-9 延续）
