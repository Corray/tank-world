## 1. 问题陈述

1. **PvE 缺「守土」玩法**：现有战役/无尽都是「清场推进」；波次防御 = 围绕基地的生存压力测试，是 PvE 第三种循环。
2. **与无尽模式的核心区隔 = 同图连续作战**：无尽是「清关→换图→全重置」过关制；波次是**一张图打到死**——地形损耗、护圈破口、场上道具、升级全部跨波累积，只有波间短暂喘息。R12 铲子（修墙）在此从增益升格为战略资源，机制天然协同。
3. **首个自动间奏状态**：既有间奏（LEVEL_CLEAR/VERSUS_ROUND）全是按键流转；WAVE_BREAK 倒计时自动开波是状态机净新维度（advance 层新分支，AC-11 冻结语义需显式守护）。

## 2. 需求清单

### F-R13-1 WAVE 模式入口（P0）

- `GameMode` 增 `WAVE`（PvE 族，isPvP 不含）；`GameState` 增 `WAVE_BREAK` / `WAVE_OVER`
- READY 按 **5** = 单人波次；按 **6** = 双人波次（OPEN-R13-3 决议=都开）
- `setupWave(world, coop)`：装载 **L1 图**（OPEN-R13-4 决议）、玩家就位、`wave=1`、灌注第一波

### F-R13-2 波次构成 waveConfig(k)（P0）

〔默认公式，手感可调〕：`total = 8 + 2k`；`armoredRatio = min(0.5, 0.15 + 0.03k)`；FAST = (total−ARMORED)/2 取整；`spawnIntervalMs = max(800, 2000 − 100k)`
- **Boss 波（OPEN-R13-2 决议）**：`isBossWave(k) = k % 5 === 0` → 该波末位注入 BOSS + total+1（复用 R11 注入模式与全部 Boss 行为）

### F-R13-3 波清 → WAVE_BREAK → 自动开波（P0，OPEN-R13-1 决议）

- 波清（`mode===WAVE && allSpawned && fieldClear`）→ `WAVE_BREAK`，`waveBreakMs = WAVE_BREAK_MS`〔默认 5s〕
- **advance 层新分支**：WAVE_BREAK 期间 `world.clock` 不动、updateWorld 不跑（实体全冻，AC-11 语义保持），仅倒计时递减；归零 → `startNextWave`（wave+1、灌新波）→ PLAYING
- 按任意动作键**可提前开波**（复用 onAnyAction 通道）
- 波清**不走** LEVEL_CLEAR：不 bank 分（score 单字段持续累积）、不调 onLevelCleared/onLevelLoaded

### F-R13-4 同图连续（P0，核心区隔）

跨波**不重建 GameMap、不清场上道具、不重置玩家**：地形损耗/护圈破口累积；STAR 升级、命数、doubleFire、定时效果（铲钢圈/冻结余窗）全部跨波保留——同一张图没换，铲子钢圈跨波正当（与 loadLevel 的清零分叉：startNextWave 不经 loadLevel，涌现保留）

### F-R13-5 失败结算与档位（P0）

- 基地毁或全员命尽 → `WAVE_OVER`：结算**完整清掉的波数**（死于第 k 波 = k−1）
- 第七档 `best-wave` / 第八档 `best-coop-wave`（OPEN-R13-3 决议=档位分离，对齐 R7 第六档先例）
- **WAVE 不写既有六档**（best-level/best-total/best-endless/coop 系——#6 教训写入点门控镜像）
- WAVE_OVER → R 键 → 全新 READY（restartToReady 扩展）

### F-R13-6 HUD 与渲染（P0/P1）

- HUD：WAVE 模式下显示 `WAVE n`（替代 LEVEL n/3）+ 第七/八档 BEST 行
- render overlay：WAVE_BREAK（"WAVE n CLEARED / next wave in …"倒计时）/ WAVE_OVER（"SURVIVED n WAVES"）

### F-R13-7 成就影响面声明（P0）

关卡族钩子波次不调用 → NO_DEATH_LEVEL/FULL_CLEAR/PURIST/CAMPAIGN/ENDLESS_8 波次天然不触发；kill/pickup/brick 族（FIRST_BLOOD/CENTURION/COLLECTOR/DEMOLITION）自然生效。`ACHIEVEMENT_COUNT` 维持 8，零成就改动。

## 3. 明确不做（本轮）

- 波间商店/建造/经济系统（超轮次粒度）
- 第 9 波次成就（成就面四轮未动先例）
- 专用守基图 / 波次图轮换（OPEN-R13-4 决议=复用 L1；轮换与「同图连续」核心区隔冲突）
- 无尽模式改造（两者并存，无尽零改）
- PvP 波次（守土是 PvE 语义）

## 4. 成功指标

- 按 5/6 进波次；波次曲线递增；每 5 波 Boss；倒计时自动开波且期间全冻；同图连续四类状态（地形/道具/升级/定时效果）跨波保留全部机器可验
- 第七/八档隔离写入；既有六档零写入（写入点级断言）
- **既有 263 测试零回归**；分叉清单 v7 基线冲击预判内零意外修订
- tsc 干净；单文件体积增量可控
